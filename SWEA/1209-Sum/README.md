# [D3] Sum

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV13_BWKACUCFAYh
- 사이트 / 난이도: SWEA / D3 ([S/W 문제해결 기본] 2일차)
- 유형: 2차원 배열, 구현
- 푼 날짜: 2026-11-17

## 문제
다음 100X100의 2차원 배열이 주어질 때, 각 행의 합, 각 열의 합, 각 대각선의 합 중 최댓값을 구하는 프로그램을 작성하여라.

다음과 같은 5X5 배열에서 최댓값은 29이다. *(원문 그림 생략)*

### 제약 사항
총 10개의 테스트 케이스가 주어진다.

배열의 크기는 100X100으로 동일하다.

각 행의 합은 integer 범위를 넘어가지 않는다.

동일한 최댓값이 있을 경우, 하나의 값만 출력한다.

### 입력
각 테스트 케이스의 첫 줄에는 테스트 케이스 번호가 주어지고 그 다음 줄부터는 2차원 배열의 각 행 값이 주어진다.

### 출력
#부호와 함께 테스트 케이스의 번호를 출력하고, 공백 문자 후 테스트 케이스의 답을 출력한다.

### 입출력 예제 (일부)
입력
```
1
13 24 13 24 1 7 24 11 22 18 ... (한 줄에 100개, 100줄)
...
```
출력
```
#1 1712
#2 1743
#3 1713
#4 1682
#5 1715
#6 1730
#7 1703
#8 1714
#9 1727
#10 1731
```

## 풀이 아이디어 (solution.cpp)
- 행 100개, 열 100개, 대각선 2개의 합을 각각 구하면서 최댓값을 갱신한다.
- 우하대각선: `map[j][j]`
- 우상대각선: `map[j][99 - j]` (행이 1 늘 때 열이 1 줄어든다)

## 시간 / 공간 복잡도
- 100×100 배열을 몇 번 훑음 → O(N²) = 약 2만 번 연산

## 헷갈렸던 점, 배운 점
- 처음에 우상대각선을 `map[j][100 - j]`로 써서 j = 0일 때 배열 밖(100번 열)을 읽었다. 크기가 N이면 마지막 인덱스는 **N - 1**이라 반대쪽 인덱스는 `N - 1 - j`.
- 테스트 데이터에서 대각선 합이 최댓값이 아니면 틀린 코드도 통과할 수 있다. 통과했다고 끝이 아니라 인덱스를 직접 확인하자.
