# [D3] 재미있는 오셀로 게임

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AWQmA4uK8ygDFAXj
- 사이트 / 난이도: SWEA / D3
- 유형: 2차원 배열, 시뮬레이션, 8방향 탐색
- 푼 날짜: 2026-11-16

## 문제
오셀로라는 게임은 흑돌과 백돌을 가진 사람이 번갈아가며 보드에 돌을 놓아서 최종적으로 보드에 자신의 돌이 많은 사람이 이기는 게임이다.

보드는 4x4, 6x6, 8x8(가로, 세로 길이) 크기를 사용한다. 6x6 보드에서 게임을 할 때, 처음에 플레이어는 다음과 같이 돌을 놓고 시작한다(B : 흑돌, W : 백돌). *(원문 그림 생략)*

4x4, 8x8 보드에서도 동일하게 정가운데에 아래와 같이 배치하고 시작한다. *(원문 그림 생략)*

그리고 흑, 백이 번갈아가며 돌을 놓는다.

처음엔 흑부터 시작하는데 이 때 흑이 돌을 놓을 수 있는 곳은 다음과 같이 4군데이다. *(원문 그림 생략)*

플레이어는 빈공간에 돌을 놓을 수 있다.

단, 자신이 놓을 돌과 자신의 돌 사이에 상대편의 돌이 있을 경우에만 그 곳에 돌을 놓을 수 있고, 그 때의 상대편의 돌은 자신의 돌로 만들 수 있다.

(여기에서 "사이"란 가로/세로/대각선을 의미한다.)

(2, 3) 위치에 흑돌을 놓은 후의 보드는 다음과 같다. *(원문 그림 생략)*

이런 식으로 번갈아가며 흑, 백 플레이어가 돌을 놓는다.

만약 돌을 놓을 곳이 없다면 상대편 플레이어가 다시 돌을 놓는다.

보드에 빈 곳이 없거나 양 플레이어 모두 돌을 놓을 곳이 없으면 게임이 끝나고 그 때 보드에 있는 돌의 개수가 많은 플레이어가 승리하게 된다.

### 입력
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.

각 테스트 케이스의 첫 번째 줄에는 보드의 한 변의 길이 N과 플레이어가 돌을 놓는 횟수 M이 주어진다. N은 4, 6, 8 중 하나이다.

그 다음 M줄에는 돌을 놓을 위치와 돌의 색이 주어진다.

돌의 색이 1이면 흑돌, 2이면 백돌이다.

만약 3 2 1이 입력된다면 (3, 2) 위치에 흑돌을 놓는 것을 의미한다.

돌을 놓을 수 없는 곳은 입력으로 주어지지 않는다.

### 출력
각 테스트 케이스마다 게임이 끝난 후 보드 위의 흑돌, 백돌의 개수를 출력한다.

흑돌이 30개, 백돌이 34인 경우 30 34를 출력한다.

## 풀이 아이디어 (solution.c)
1. 가운데 4칸에 초기 돌 배치 (1 흑, 2 백).
2. 돌을 놓을 때마다 **8방향**(`dy[8]`, `dx[8]`)을 각각 확인한다.
   - 바로 옆이 상대 돌이면 그 방향으로 **상대 돌이 이어지는 동안** 전진하며 개수(`cnt`)를 센다.
   - 멈춘 칸이 **판 안이고 내 돌이면** → 되돌아오며 `cnt`개를 내 색으로 뒤집는다.
   - 빈칸이나 판 밖에서 멈추면 그 방향은 뒤집지 않는다.
3. 마지막에 흑·백 개수를 센다.

## 시간 / 공간 복잡도
- 돌 하나당 8방향 × 최대 N칸 → O(M × 8N), 공간 O(N²)

## 헷갈렸던 점, 배운 점
- **배열 밖 접근**: 처음엔 범위 검사 없이 `map[cy][cx]`, `map[ny][nx]`를 읽고 썼다.
  - 가장자리에 놓으면 좌표가 -1이 되어 **다른 변수의 메모리를 읽고 덮어씀** → VS에서는 반복 변수가 망가져 돌을 11개만 놓고 끝났고, SWEA에서는 우연히 통과했다.
  - "제출하면 정답인데 내 PC에선 다르다" = 배열 밖 접근을 의심하자.
- 범위 검사는 `0 <= ny && ny < N && 0 <= nx && nx < N && map[ny][nx] == ...`처럼 **항상 맨 앞에**. `&&`는 앞이 거짓이면 뒤를 실행하지 않는다.
- 읽기(`if`, `while` 조건)와 쓰기(뒤집기) **모든 곳**에 범위 검사가 필요하다.
- 다른 방법: 좌표를 1부터 쓰고 배열을 `N+2`로 잡아 **0 테두리**를 두면 범위 검사 없이 멈춘다 (1979, Ladder1에서 쓴 방법).
- VS2017에서 `scanf`, `setbuf` 에러(C4996) → 파일 **맨 위**에 `#define _CRT_SECURE_NO_WARNINGS`.
