# [D2] 숫자 배열 회전

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV5Pq-OKAVYDFAUq
- 사이트 / 난이도: SWEA / D2
- 유형: 2차원 배열, 구현(회전)
- 푼 날짜: 2026-11-13

## 문제
N x N 행렬이 주어질 때,

시계 방향으로 90도, 180도, 270도 회전한 모양을 출력하라.

### 제약 사항
N은 3 이상 7 이하이다.

### 입력
가장 첫 줄에는 테스트 케이스의 개수 T가 주어지고, 그 아래로 각 테스트 케이스가 주어진다.

각 테스트 케이스의 첫 번째 줄에 N이 주어지고,

다음 N 줄에는 N x N 행렬이 주어진다.

### 출력
출력의 첫 줄은 '#t'로 시작하고,

다음 N줄에 걸쳐서 90도, 180도, 270도 회전한 모양을 출력한다.

입력과는 달리 출력에서는 회전한 모양 사이에만 공백이 존재함에 유의하라.

(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

## 풀이 아이디어 (solution.cpp)
**시계방향 90도 회전 공식**: 회전 후 `(j, i)` 칸 = 회전 전 `(N-1-i, j)` 칸
- 회전 후 첫 줄은 원래 **첫 열을 아래에서 위로** 읽은 것이다.

이 공식을 3번 적용하면 90도 → 180도 → 270도가 나온다.
`map[j][i][k]`의 세 번째 인덱스로 회전 결과를 따로 저장한다(0: 원본, 1: 90도, 2: 180도, 3: 270도).
출력은 줄마다 90도, 180도, 270도 배열의 같은 행을 공백으로 이어 붙인다.

예) N=3
```
원본    90도  180도  270도
1 2 3   741   987   369
4 5 6   852   654   258
7 8 9   963   321   147
```

## 시간 / 공간 복잡도
- O(N²) × 3번, 공간 O(N²)

## 헷갈렸던 점, 배운 점
- 출력 반복문을 `k <= N`으로 써서 N=3일 때만 우연히 맞았다. N=4부터는 없는 `map[..][..][4]`를 읽어 **쓰레기 값**이 한 묶음 더 출력된다.
  → 회전 결과는 항상 3개이므로 `k <= 3`. "이 숫자가 N이 맞나?"를 꼭 확인하자.
- 예제가 N=3 하나뿐이면 N=4 같은 다른 크기로도 직접 테스트해 보기.
- 회전 공식은 외우기보다 "첫 줄 = 첫 열을 아래에서 위로"를 떠올리면 바로 만들 수 있다.
