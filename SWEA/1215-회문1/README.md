## 문제
"기러기", "토마토", "스위스"와 같이 똑바로 읽어도 거꾸로 읽어도 똑같은 문장이나 낱말을 회문(回文, palindrome)이라 한다.

8x8 평면 글자판에서 제시된 길이를 가진 회문의 개수를 구하라.

*(원문 그림 생략)*

위와 같은 글자판이 주어졌을 때, 길이가 5인 회문은 붉은색 테두리로 표시된 4개이므로 4를 반환하면 된다.

### 제약 사항
각 칸의 들어가는 글자는 'A', 'B', 'C' 중 하나이다.

ABA도 회문이며, ABBA도 회문이다. A 또한 길이 1짜리 회문이다.

가로 또는 세로로 이어진 회문의 개수만 센다.

아래 그림에서 노란색 경로를 따라가면 길이 7짜리 회문이 되지만 직선이 아니기 때문에 인정되지 않는다. *(원문 그림 생략)*

### 입력
총 10개의 테스트 케이스가 주어진다.

각 테스트 케이스의 첫 번째 줄에는 찾아야 하는 회문의 길이가 주어지며, 다음 줄에 8x8 크기의 글자판이 주어진다.

### 출력
#부호와 함께 테스트 케이스의 번호를 출력하고, 공백 문자 후 찾은 회문의 개수를 출력한다.

## 풀이 아이디어 (solution.cpp)
모든 칸 `(j, i)`를 회문의 **시작점**으로 놓고, 가로·세로로 길이 `size`인 구간이 회문인지 확인한다.
- 회문 확인: 양 끝에서 안쪽으로 `k = 0 ~ size/2 - 1`까지 `앞쪽 k번째 == 뒤쪽 k번째`인지 비교
  - 가로: `map[j][i + k]` vs `map[j][i + size - k - 1]`
  - 세로: `map[j + k][i]` vs `map[j + size - k - 1][i]`
- 구간이 판 밖으로 나가면 회문이 아니다 (범위 검사 후 `return 0`).

## 시간 / 공간 복잡도
- 64칸 × 2방향 × size/2 → 상수 시간, 공간 O(1)

## 헷갈렸던 점, 배운 점
- `char sen[8];`로 8글자를 받았더니 모든 케이스가 **128**이 나왔다.
  - `cin >> sen`은 끝에 `'\0'`을 붙이므로 **글자 수 + 1칸**이 필요하다. 넘친 `'\0'`이 옆 변수 `size`를 0으로 덮어써서 모든 칸이 회문으로 세졌다 (64칸 × 2 = 128).
  - → `char sen[9];` 문자열 배열은 항상 **글자 수 + 1** (넉넉히 잡아도 된다).
- 오셀로(4615)와 같은 종류의 버그: 배열 밖에 쓰면 **다른 변수가 조용히 망가진다.** 결과가 전부 같은 값이면 의심하자.
