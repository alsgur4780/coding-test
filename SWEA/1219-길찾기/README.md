# [D4] 길찾기

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV14geLqABQCFAYD
- 사이트 / 난이도: SWEA / D4 ([S/W 문제해결 기본] 4일차)
- 유형: 그래프, DFS(재귀)
- 푼 날짜: 2026-11-16

## 문제
그림과 같이 도식화한 지도에서 A도시에서 출발하여 B도시로 가는 길이 존재하는지 조사하려고 한다. *(원문 그림 생략)*

길 중간 중간에는 최대 2개의 갈림길이 존재하고, 모든 길은 일방 통행으로 되돌아오는 것이 불가능하다.

다음과 같이 길이 주어질 때, A도시에서 B도시로 가는 길이 존재하는지 알아내는 프로그램을 작성하여라.
- A와 B는 숫자 0과 99으로 고정된다.
- 모든 길은 순서쌍으로 나타내어진다. 위 예시에서 2번에서 출발 할 수 있는 길의 표현은 (2, 5), (2, 9)로 나타낼 수 있다.
- 가는 길의 개수와 상관없이 한가지 길이라도 존재한다면 길이 존재하는 것이다.
- 단 화살표 방향을 거슬러 돌아갈 수는 없다.

### 제약 사항
출발점은 0, 도착점은 99으로 표현된다.

정점(분기점)의 개수는 98개(출발점과 도착점 제외)를 넘어가지 않으며, 한 개의 정점에서 선택할 수 있는 길의 개수도 2개를 넘어가지 않는다.

아래 제시된 가이드 라인은 제안사항일 뿐 강제사항은 아니다.

### 데이터 저장 가이드
정점(분기점)의 개수가 최대 100개 이기 때문에, size [100]의 정적 배열 2개을 선언하여, 각 정점의 번호를 주소로 사용하고, 저장되는 데이터는 각 정점에서 도착하는 정점의 번호를 저장한다.

위 그림을 저장하였을 때 결과는 다음과 같다. *(원문 그림 생략)*

### 입력
총 10개의 테스트 케이스가 주어진다.

각 테스트 케이스의 첫 줄에는 테스트 케이스의 번호와 길의 총 개수가 공백으로 분리되어 주어진다.

그 다음 줄에는 순서쌍이 주어진다. 순서쌍의 경우, 별도로 나누어 표현되는 것이 아니라 숫자의 나열이며, 나열된 순서대로 순서쌍을 이룬다.

### 출력
#부호와 함께 테스트 케이스의 번호를 출력하고, 공백 문자 후 테스트 케이스에 대한 답(가능 여부)을 출력한다.

가능할 경우 1, 불가능할 경우 0을 출력한다.

### 입출력 예제 (일부)
입력
```
1 16
0 1 0 2 1 4 1 3 4 8 4 3 2 9 2 5 5 6 5 7 7 99 7 9 9 8 9 10 6 10 3 7
2 159
...
```
출력
```
#1 1
#2 1
#3 1
#4 0
#5 1
#6 1
#7 0
#8 0
#9 0
#10 0
```

## 풀이 아이디어 (solution.cpp)
각 점에서 나가는 길이 **최대 2개**라서 `map[0][a]`, `map[1][a]` 두 배열에 나가는 곳을 저장한다.
- 입력 `a b`: `map[0][a]`가 비어 있으면 거기에, 아니면 `map[1][a]`에 `b`를 넣는다.
- `dfs(0)`부터 출발해서 갈 수 있는 길을 재귀로 따라간다.
  - 99에 도착하면 1을 반환하고, 한 번이라도 1이 돌아오면 바로 1을 위로 전달한다.
  - 두 길 모두 실패하면 0.

## 시간 / 공간 복잡도
- 점 100개, 길 최대 200개 → 매우 작음, 공간 O(100)

## 헷갈렸던 점, 배운 점
- **2차원 배열을 함수에 넘기기**: `int**`는 안 된다. 열 크기를 적어야 한다 → `int map[2][100]`, `int map[][100]`, `int (*map)[100]`. (전역 배열로 두면 안 넘겨도 된다)
- **초기화**: `int map[2][100] = { -1, };`은 **첫 칸만 -1**, 나머지는 0이다. 전체 -1은 `memset(map, -1, sizeof(map))` (memset은 0과 -1만 가능).
- `= { 0, }`은 전체 0이 맞다. 그래서 "비어 있음"을 0으로 표시했다 (0번 점으로 가는 길은 없으므로 가능).
- 재귀 결과를 **반환값**으로 전달해야 한다. `int result`를 인자로 넘겨서 `result++` 하면 복사본만 바뀌어 원래 값은 그대로다.
