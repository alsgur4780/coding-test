# [D4] 길찾기

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV14geLqABQCFAYD
- 사이트 / 난이도: SWEA / D4 ([S/W 문제해결 기본] 4일차)
- 유형: 그래프, DFS(재귀)
- 푼 날짜: 2026-11-16

## 문제
> 문제 지문은 추가 예정

## 풀이 아이디어 (solution.cpp)
각 점에서 나가는 길이 **최대 2개**라서 `map[0][a]`, `map[1][a]` 두 배열에 나가는 곳을 저장한다.
- 입력 `a b`: `map[0][a]`가 비어 있으면 거기에, 아니면 `map[1][a]`에 `b`를 넣는다.
- `dfs(0)`부터 출발해서 갈 수 있는 길을 재귀로 따라간다.
  - 99에 도착하면 1을 반환하고, 한 번이라도 1이 돌아오면 바로 1을 위로 전달한다.
  - 두 길 모두 실패하면 0.

## 시간 / 공간 복잡도
- 점 100개, 길 최대 200개 → 매우 작음, 공간 O(100)

## 헷갈렸던 점, 배운 점
- **2차원 배열을 함수에 넘기기**: `int**`는 안 된다. 열 크기를 적어야 한다 → `int map[2][100]`, `int map[][100]`, `int (*map)[100]`. (전역 배열로 두면 안 넘겨도 된다)
- **초기화**: `int map[2][100] = { -1, };`은 **첫 칸만 -1**, 나머지는 0이다. 전체 -1은 `memset(map, -1, sizeof(map))` (memset은 0과 -1만 가능).
- `= { 0, }`은 전체 0이 맞다. 그래서 "비어 있음"을 0으로 표시했다 (0번 점으로 가는 길은 없으므로 가능).
- 재귀 결과를 **반환값**으로 전달해야 한다. `int result`를 인자로 넘겨서 `result++` 하면 복사본만 바뀌어 원래 값은 그대로다.
