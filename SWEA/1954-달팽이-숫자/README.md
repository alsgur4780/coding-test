# [D2] 달팽이 숫자

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV5PobmqAPoDFAUq
- 사이트 / 난이도: SWEA / D2
- 유형: 2차원 배열, 구현(시뮬레이션), 방향 배열
- 푼 날짜: 2026-11-13

## 문제
달팽이는 1부터 N*N까지의 숫자가 시계방향으로 이루어져 있다.

다음과 같이 정수 N을 입력 받아 N크기의 달팽이를 출력하시오.

### 예제
N이 3일 경우,
```
1 2 3
8 9 4
7 6 5
```
N이 4일 경우,
```
1  2  3  4
12 13 14 5
11 16 15 6
10 9  8  7
```

### 제약사항
달팽이의 크기 N은 1 이상 10 이하의 정수이다. (1 ≤ N ≤ 10)

### 입력
가장 첫 줄에는 테스트 케이스의 개수 T가 주어지고, 그 아래로 각 테스트 케이스가 주어진다.

각 테스트 케이스에는 N이 주어진다.

### 출력
각 줄은 '#t'로 시작하고, 다음 줄부터 빈칸을 사이에 두고 달팽이 숫자를 출력한다.

(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

## 풀이 아이디어 (solution.cpp)
방향 배열 `dy`, `dx`에 **오른쪽 → 아래 → 왼쪽 → 위** 순서를 넣어 두고, 숫자를 1부터 N*N까지 채우며 이동한다.
1. 현재 칸에 숫자 `i`를 쓴다.
2. 지금 방향으로 한 칸 앞(`cy`, `cx`)을 본다.
3. 범위 안이고 비어 있으면(0) 그대로 이동한다.
4. **벽이거나 이미 채운 칸이면** `d = (d + 1) % 4`로 시계방향 회전 후 이동한다.

N=3 예시: 1→2→3 (오른쪽 벽) → 회전 → 4→5 (아래 벽) → 회전 → 6→7 (왼쪽 벽) → 회전 → 8 (1이 있음) → 회전 → 9

## 시간 / 공간 복잡도
- O(N²) (칸마다 한 번씩), 공간 O(N²)

## 헷갈렸던 점, 배운 점
- 처음 코드의 실수 3가지
  1. `for (...; i <= N * N; N++)` → `i++` 대신 `N++`을 써서 무한 루프
  2. 다음 칸이 **배열 밖**일 때 회전 처리가 없어서 제자리에 멈춤 → "밖이거나 채운 칸이면 회전"을 한 조건으로 묶음
  3. 전역 배열을 케이스마다 초기화하지 않음 → 배열을 반복문 안에 `= { 0, }`으로 선언해서 해결 (`memset`도 가능)
- 방향 배열 + `(d + 1) % 4` 회전은 시뮬레이션 문제에서 계속 쓰는 패턴이다.
- VS에서 LNK1168(exe를 쓰기용으로 열 수 없음) 에러는 이전 실행 창이 안 닫혀서 생긴다 → 콘솔 창 닫거나 작업 관리자에서 종료.
- `map`은 `std::map`과 이름이 겹칠 수 있으니 `board` 같은 이름이 안전하다.
