# [Lv.2] 다리를 지나는 트럭

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42583
- 사이트 / 난이도: 프로그래머스 / Lv.2
- 유형: 스택/큐, 시뮬레이션
- 푼 날짜: 2026-10-17

## 풀이 아이디어 (solution.cpp, 내 풀이)
1초씩 시간을 늘리며 시뮬레이션한다.
- 트럭마다 다리 위에 있었던 시간 `truck_time[i]`를 센다.
- 다리 위 트럭은 `cnt_bridge`(맨 앞)부터 `cnt_ready - 1`(맨 뒤)까지다. 이 범위만 한 칸씩 움직인다.
- `truck_time[i] == bridge_length`가 되면 다리에서 내리고 무게를 뺀다.
- 그다음, 무게와 대수에 여유가 있으면 다음 트럭을 올린다.

## 더 쉬운 풀이 (solution_easy.cpp)
다리를 길이 `bridge_length`짜리 큐로 보고 처음에 0(빈 칸)으로 채운다. 매초
1. 맨 앞 칸을 pop하고 그 무게를 뺀다 (트럭이 내리거나 빈 칸이 빠짐)
2. 다음 트럭을 올릴 수 있으면 그 무게를, 아니면 0을 push한다

큐 길이가 항상 `bridge_length`라서 "다리 위 트럭 수" 조건은 자동으로 지켜진다.
마지막 트럭을 올린 뒤에는 `bridge_length`초가 더 지나야 다 건너므로 `time + bridge_length`를 반환한다.

## 시간 / 공간 복잡도
- 내 풀이: 매초 다리 위 트럭을 모두 움직여서 최악 O(시간 × bridge_length)
- 쉬운 풀이: 매초 push/pop 한 번씩이라 O(전체 시간) = O(N × bridge_length)보다 작거나 같음, 공간 O(bridge_length)

## 헷갈렸던 점, 배운 점
- `queue`는 `[i]`로 접근할 수 없다. 큐에서 pop하면 별도 배열의 인덱스와 어긋난다.
- 종료 조건은 "트럭을 **다** 올렸고 다리가 비었을 때" (`cnt == 전체`), `<`나 `<=`를 헷갈리지 말 것.
- `truck_weights[cnt]`를 읽기 전에 `cnt < 전체`를 먼저 검사해야 범위 초과(segfault)가 안 난다. `&&`는 앞이 거짓이면 뒤를 계산하지 않는다.
- 매초 순서: **내리기 먼저, 올리기 나중**.
