# [Lv.2] 게임 맵 최단거리

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/1844
- 사이트 / 난이도: 프로그래머스 / Lv.2
- 유형: BFS (너비 우선 탐색)
- 푼 날짜: 2026-11-12

## 풀이 아이디어
최단 거리는 BFS로 구한다. 시작점에서 가까운 칸부터 차례로 퍼져 나가므로, 도착점에 처음 닿았을 때의 거리가 곧 최솟값이다.
- 배열 두 개(`qy`, `qx`)와 `head`, `tail`로 큐를 직접 구현했다.
- `chk[y][x]`에 "그 칸까지 지나온 칸 수"를 저장한다. 시작 칸이 1이므로 방문 표시와 거리를 한 번에 처리한다.
- 동서남북 4방향(`dy`, `dx`)으로 이동하면서, 맵 안이고 벽이 아니고 처음 가는 칸이면 큐에 넣는다.
- 도착점 `(n-1, m-1)`에 닿으면 `chk + 1`을 반환하고, 큐가 비면 도달할 수 없으므로 -1을 반환한다.

## 시간 / 공간 복잡도
- 시간: O(n × m), 모든 칸을 최대 한 번씩 방문
- 공간: O(n × m)

## 헷갈렸던 점, 배운 점
- 범위 검사는 **이동한 뒤의 좌표**(`cy`, `cx`)로 해야 한다. 처음에 `0 <= nx && nx < m`처럼 현재 좌표로 검사해서 `maps[cy][-1]`을 읽는 버그가 있었다. (운이 좋으면 통과하지만 정의되지 않은 동작이다.)
- 전역 변수(`chk`, `head`, `tail`)는 `solution`이 여러 번 불리면 이전 값이 남는다. 함수 안에서 초기화하거나 지역 변수로 쓰는 게 안전하다.
