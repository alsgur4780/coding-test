# 올바른 괄호

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12909
- 사이트 / 난이도: 프로그래머스 / Lv.2
- 유형: 스택/큐
- 언어: C
- 푼 날짜: 2026-10-17

## 풀이 아이디어
스택 대신 열린 괄호 개수 `cnt`만 센다.
- `(`이면 `cnt++`
- `)`이면 짝지을 `(`가 있을 때만(`cnt > 0`) `cnt--`, 없으면 바로 실패
- 끝까지 읽은 뒤 `cnt`가 0이어야 모든 괄호가 닫힌 것

괄호 종류가 하나뿐이라 스택에 무엇이 들어 있는지는 필요 없고 개수만 알면 된다.

## 시간 / 공간 복잡도
- 시간: O(N), 문자열을 한 번 순회
- 공간: O(1)

## 헷갈렸던 점, 배운 점
- 문자열 끝 널 문자는 `'\0'`(역슬래시). `'/0'`으로 쓰면 끝을 못 찾고 메모리 밖까지 읽는다.
- 반복이 끝난 뒤 `cnt != 0`인지 꼭 확인해야 `"(()"` 같은 입력을 걸러낸다.
