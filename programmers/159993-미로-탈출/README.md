# [Lv.2] 미로 탈출

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/159993
- 사이트 / 난이도: 프로그래머스 / Lv.2
- 유형: BFS
- 푼 날짜: 2026-10-23

## 풀이 아이디어 (solution.c)
레버를 당기면 그 자리에서 새로 출발하는 것과 같으므로 BFS를 두 번 돌린다.
1. S → L 최단거리
2. 방문 배열을 초기화하고 L → E 최단거리
3. 둘 중 하나라도 도착 못 하면 -1, 아니면 두 거리의 합

시작 칸을 `chk = 1`로 두고 거리를 `chk[이웃] = chk[지금] + 1`로 넘긴 뒤, 도착하면 1을 뺀다.

## 시간 / 공간 복잡도
- BFS 두 번: O(N × M), 공간 O(N × M)

## 헷갈렸던 점, 배운 점
- 크기가 변수인 배열(`int chk[maps_len][maps_len]`)은 `= {0,}`으로 초기화할 수 없다 → 최대 크기로 전역에.
- `const` 원본은 복사하지 말고 `maps[y][x]`로 바로 읽는다. 글자 지도에 `- '0'`을 하면 안 된다.
- 직사각형이라 가로 길이는 `maps_len`이 아니라 한 줄의 길이(마지막 번호 + 1, 또는 `strlen(maps[0])`).
- 두 번째 BFS도 시작 칸에 방문 표시를 해야 거리가 1 모자라지 않는다.
- if 안에서 `int find_end = 1;`처럼 `int`를 다시 붙이면 바깥 변수가 안 바뀐다 (디스크 컨트롤러에서도 같은 실수).
