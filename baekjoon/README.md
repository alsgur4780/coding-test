# 백준 풀이 알고리즘 정리

백준에서 푼 문제의 핵심 알고리즘과 풀이 흐름을 정리합니다. 새 문제를 풀 때마다 아래에 추가합니다.

## 문제 보고 알고리즘 떠올리기

| 신호 | 떠올릴 것 | 예시 |
|---|---|---|
| 격자/지도, "최단 거리", "최소 칸 수" | BFS | 미로 탈출 |
| 가장 작은/큰 것을 계속 꺼낸다, 작업 순서 | 힙 (우선순위 큐) | 디스크 컨트롤러 |
| 모든 섬/도시를 최소 비용으로 연결 | MST (크루스칼 + 유니온파인드) | 섬 연결하기 |
| "최소 K", K 범위가 매우 큼, "K면 되나?" 확인은 쉬움 | 이분탐색 (매개변수 탐색) | 6236, 입국심사 |
| 두 수의 합/차, 정렬해도 됨 | 정렬 + 투 포인터 | 1253 |
| "A를 B보다 먼저" 같은 순서 조건 | 위상 정렬 (+ 작은 것부터면 힙) | 1766 |
| 넣거나 안 넣거나, 최대 가치 | DP (배낭) | 12865 |
| N이 10~15 이하로 작음 | 완전탐색 / 백트래킹 | 피로도 |

**제한으로 거르기** (1초 ≈ 1억 번): N ≤ 10 → 전부 해보기 / N ≤ 2,000 → O(N²) / N ≥ 100,000 → O(N log N) 이하

**시험장 전략**: 떠오르지 않으면 무식한 방법이라도 먼저 제출해서 부분 점수를 챙기고, 그다음 위 표를 보며 개선한다.

## 1253 좋다

**문제 요약**
N개의 수 중에서, **다른 두 수의 합**으로 나타낼 수 있는 수(좋은 수)의 개수를 구한다.
N ≤ 2,000, |값| ≤ 1,000,000,000. 같은 값이 여러 번 나올 수 있고, 위치가 다르면 다른 수로 본다.

**왜 3중 for문은 안 되나**
- i, j, k를 전부 도는 방법은 2000³ = 80억 번 → 시간 초과.
- 같은 k를 여러 쌍(1+3, 3+1 …)으로 중복해서 세서 답도 커진다. "좋은 수의 **개수**"라서 k 하나당 최대 1번만 센다.

**알고리즘: 정렬 + 투 포인터**
1. 배열을 오름차순 정렬한다.
2. 검사할 수 `num[k]`마다 `i = 0`(제일 작은 쪽), `j = N-1`(제일 큰 쪽)에서 시작한다.
3. `i == k`나 `j == k`이면 자기 자신은 못 쓰니 건너뛴다.
4. `s = num[i] + num[j]`
   - `s == num[k]` → 좋은 수! 세고 바로 다음 k로 (`break`)
   - `s < num[k]` → 합을 키워야 하니 `i++`
   - `s > num[k]` → 합을 줄여야 하니 `j--`
5. 정렬돼 있어서 포인터를 한 방향으로만 움직여도 모든 후보를 놓치지 않는다.

**복잡도**: k마다 while이 최대 N번 → O(N²) = 400만 번.

```cpp
sort(num, num + N);
for (int k = 0; k < N; k++) {
    int i = 0, j = N - 1;
    while (i < j) {
        if (i == k) { i++; continue; }
        if (j == k) { j--; continue; }
        long long s = num[i] + num[j];
        if (s == num[k]) { cnt++; break; }
        else if (s < num[k]) i++;
        else j--;
    }
}
```

**헷갈렸던 점**
- 값이 최대 10억이라 두 수를 더하면 int 범위(약 21억)를 넘을 수 있다 → `long long`, 입력은 `%lld`.
- `scanf_s`는 Visual Studio 전용 → 시험장에서는 `scanf`. (VS에서는 맨 위에 `#define _CRT_SECURE_NO_WARNINGS`)
- C++ `sort`는 `using namespace std;`가 있어야 한다. C는 `qsort` + cmp 함수(`(p > q) - (p < q)`).
- 음수, 0이 섞여 있어도 정렬 + 투 포인터로 그대로 된다 (예: 0 0 0 → 3개 모두 좋은 수).

## 6236 용돈 관리

**문제 요약**
N일 동안 매일 쓸 돈이 정해져 있다. 은행에서 한 번에 **K원씩만** 인출할 수 있고, 지갑 돈이 오늘 쓸 돈보다 모자라면 남은 돈을 넣고 다시 K원을 인출한다. 인출을 **M번 이하**로 하게 만드는 **최소 K**를 구한다.
N, M ≤ 100,000, 하루 금액 ≤ 10,000.

**아이디어: "K를 정해놓고 되는지 확인" + 업다운 게임**
- K를 하나 정하면 인출 횟수는 하루씩 따라가며 O(N)에 셀 수 있다 → `count(K)`
- K가 클수록 인출 횟수는 줄어든다. 그래서 "되는 K"와 "안 되는 K"가 경계 하나로 나뉜다 → 이분탐색으로 경계를 찾는다.
- 이렇게 "답을 직접 구하기 어려울 때, 답을 하나 찍고 되는지 확인하는 문제로 바꾸는 것"을 **매개변수 탐색(파라메트릭 서치)** 이라고 한다. (프로그래머스 입국심사, 징검다리도 같은 유형)

**탐색 범위**
- `lo` = 하루 금액 중 최댓값: 이보다 작으면 그날 쓸 돈을 한 번에 못 뽑아서 불가능
- `hi` = 전체 합: 처음 1번 뽑은 돈으로 N일을 다 쓸 수 있어서 무조건 성공
- 답은 항상 `lo ≤ K ≤ hi` 안에 있다.

**예제 따라가기** (`100 400 300 100 500 101 400`, M=5, lo=500, hi=1901)
| lo | hi | mid | 인출 횟수 | M 이하? |
|---|---|---|---|---|
| 500 | 1901 | 1200 | 2 | 된다 → hi=1199 |
| 500 | 1199 | 849 | 3 | 된다 → hi=848 |
| … | | | | |
| 500 | 500 | 500 | 5 | 된다 → hi=499, 끝 |

답 500. 1401개를 다 해보지 않고 10번 만에 찾는다.

```cpp
int count(int k) {
    int now_money = k;
    int cnt = 1;                         // 처음에 1번 뽑고 시작
    for (int i = 0; i < N; i++) {
        if (money[i] <= now_money) now_money -= money[i];   // 지갑 돈으로 충분
        else { cnt++; now_money = k - money[i]; }           // 모자라면 새로 뽑기
    }
    return cnt;
}

int ans = hi;
while (lo <= hi) {
    int mid = (lo + hi) / 2;
    if (count(mid) <= M) { ans = mid; hi = mid - 1; }   // 된다 → 더 작은 K 시도
    else lo = mid + 1;                                  // 안 된다 → K 키우기
}
```

**복잡도**: count가 O(N), 이분탐색이 log(합) ≈ 30번 → O(N log(합)).

**헷갈렸던 점**
- count에서 비교 대상은 K가 아니라 **지금 지갑에 남은 돈**(`now_money`).
- 처음 인출도 1번이다 → `cnt = 1`로 시작.
- 모자랄 때 지갑은 `+= k`가 아니라 `= k` (남은 돈은 통장에 넣으니까).
- 이분탐색에서 `mid++`/`mid--`가 아니라 **`lo`, `hi`를 움직인다**. mid는 매번 새로 계산된다.
- **된다 → `hi = mid - 1`, 안 된다 → `lo = mid + 1`**. `lo = mid - 1`로 쓰면 무한루프. 반복 조건은 `lo <= hi`.

## 12865 평범한 배낭

**문제 요약**
물건 N개(무게 W, 가치 V)가 있고, 배낭에는 최대 무게 K까지 넣을 수 있다. 각 물건은 넣거나 안 넣거나 둘 중 하나. 가치 합의 최댓값을 구한다.
N ≤ 100, K ≤ 100,000.

**왜 그냥은 안 되나**
- 가치 큰 것부터 넣기(그리디): 예제에서 13짜리(무게 6)를 넣으면 남은 1로 아무것도 못 넣어서 13 → 틀림 (정답 14)
- 모든 조합: 2¹⁰⁰가지 → 불가능

**DP란?**
작은 문제의 답을 표에 적어두고, 그걸 이어 붙여서 큰 문제의 답을 만드는 것.
예) 계단을 1칸 또는 2칸씩 오를 때 10번째 칸까지 가는 방법 수: `ways[10] = ways[9] + ways[8]`. 작은 칸부터 표를 채우면 이미 구한 값을 다시 쓰니까 빠르다.

DP 문제는 항상 3단계:
1. **표의 의미 정하기** — `dp[w]` = 배낭 한도가 w일 때 최대 가치 ("가방 크기별 최고 기록판")
2. **점화식** — 물건(W, V)이 들어오면 `dp[w] = max(dp[w], dp[w - W] + V)`
   - 안 넣으면 지금 기록 `dp[w]`
   - 넣으면 W만큼 공간을 쓰고, 남는 공간의 최고 기록 `dp[w - W]`에 V를 더한 값
3. **시작값** — 전부 0

**작은 예제** (K=5, A(3,6), B(2,5))
| | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 시작 | 0 | 0 | 0 | 0 | 0 | 0 |
| A(3,6) 후 | 0 | 0 | 0 | 6 | 6 | 6 |
| B(2,5) 후 | 0 | 0 | 5 | 6 | 6 | **11** |

크기 5 가방: B를 넣으면 남는 공간 3의 기록 6 + 5 = 11 → A, B 둘 다 넣은 것.

```cpp
int dp[100005];   // 전역이라 0으로 시작
for (int i = 0; i < N; i++) {
    int W, V;
    scanf("%d %d", &W, &V);
    for (int w = K; w >= W; w--)          // 큰 가방부터 거꾸로
        if (dp[w - W] + V > dp[w])
            dp[w] = dp[w - W] + V;
}
printf("%d", dp[K]);
```

**복잡도**: 물건 N개 × 가방 크기 K → 100 × 100,000 = 1,000만 번.

**헷갈렸던 점**
- 반복 범위는 `w = K`부터 `w >= W`까지. W부터 시작하면 큰 가방을 못 보고, 0까지 내려가면 `dp[w - W]`가 음수 인덱스(배열 밖)가 된다.
- **거꾸로(큰 w → 작은 w) 도는 이유**: 앞에서부터 돌면 이번 물건으로 갱신된 작은 칸을 큰 칸에서 또 써서 같은 물건을 두 번 넣게 된다.
- 답은 `dp[N]`이 아니라 `dp[K]` (N은 물건 개수, K가 배낭 한도).

## 9184 신나는 함수 실행

**문제 요약**
아래 재귀 함수 `w(a, b, c)`의 값을 빠르게 구한다. 입력은 `-1 -1 -1`이 나올 때까지 여러 줄 (-50 ≤ a, b, c ≤ 50). 출력 형식 `w(a, b, c) = 값`.
```
a <= 0 또는 b <= 0 또는 c <= 0  → 1
a > 20 또는 b > 20 또는 c > 20  → w(20, 20, 20)
a < b < c                     → w(a, b, c-1) + w(a, b-1, c-1) - w(a, b-1, c)
그 외                          → w(a-1, b, c) + w(a-1, b-1, c) + w(a-1, b, c-1) - w(a-1, b-1, c-1)
```

**왜 그냥 재귀는 안 되나**
호출 한 번이 3~4번씩 다시 호출하고, 같은 (a, b, c)를 수없이 다시 계산한다 → 지수 시간.

**알고리즘: 재귀 + 메모이제이션**
- 메모이제이션 = **계산한 결과를 표에 적어두고, 다음에 같은 값을 물으면 표에서 바로 꺼내는 것**. 재귀로 하는 DP.
- 실제로 계산되는 칸은 0~20 범위뿐이라 `memo[21][21][21]`이면 충분하다.
- w 함수 순서:
  1. 0 이하면 1 리턴
  2. 20 초과면 `w(20, 20, 20)` 리턴
  3. **표에 있으면 바로 리턴** ← 추가된 줄
  4. 규칙대로 계산 → **표에 적고** 리턴 ← 추가된 줄

```c
int memo[21][21][21];

int w(int a, int b, int c) {
    if (a <= 0 || b <= 0 || c <= 0) return 1;
    if (a > 20 || b > 20 || c > 20) return w(20, 20, 20);
    if (memo[a][b][c] != 0) return memo[a][b][c];      // 이미 계산했으면 꺼내기

    int r;
    if (a < b && b < c) r = w(a, b, c-1) + w(a, b-1, c-1) - w(a, b-1, c);
    else r = w(a-1, b, c) + w(a-1, b-1, c) + w(a-1, b, c-1) - w(a-1, b-1, c-1);
    return memo[a][b][c] = r;                          // 적어두고 리턴
}

// main
while (1) {
    scanf("%d %d %d", &a, &b, &c);
    if (a == -1 && b == -1 && c == -1) break;
    printf("w(%d, %d, %d) = %d\n", a, b, c, w(a, b, c));
}
```

**복잡도**: 표의 칸 21³ ≈ 9,000개를 각각 한 번만 계산.

**헷갈렸던 점**
- 20 초과 조건을 `> 0`으로 잘못 써서 아래 규칙이 실행되지 않았다. 재귀 호출 앞에 `return`도 필수.
- 표 확인은 main이 아니라 **w 함수 안**에서 해야 재귀 호출마다 효과가 있다. main에서 `memo[a][b][c]`를 보면 a = -1, 50일 때 배열 밖을 읽는다.
- 표 확인은 **범위 체크 두 개 다음**에 한 번만 쓰면 된다 (그래야 인덱스가 항상 0~20).
- 출력 형식의 쉼표 뒤 공백까지 똑같이.

## 1766 문제집

**문제 요약**
1~N번 문제(번호가 작을수록 쉬움)를 모두 푼다. "A번을 B번보다 먼저" 조건이 M개 있고, 가능하면 쉬운 문제부터 푼다. 푸는 순서를 출력한다.
N ≤ 32,000, M ≤ 100,000. 예제: 조건 `4→2`, `3→1` → `3 1 4 2`

**알고리즘: 위상 정렬 + 최소 힙**
- **위상 정렬** = 순서 조건(선행 관계)을 지키면서 일렬로 세우는 것.
- `indeg[x]` = x를 풀기 전에 먼저 풀어야 하는 문제 수. 0이면 지금 풀 수 있다.
1. 조건 A→B마다 연결 목록에 저장하고 `indeg[B]++`
2. indeg가 0인 문제를 전부 최소 힙에 넣는다
3. 힙에서 가장 작은 번호를 꺼내 출력 → 연결된 문제들의 indeg를 1씩 줄이고, 0이 되면 힙에 넣는다
4. 힙이 빌 때까지 반복

**왜 일반 큐로는 안 되나**
큐 `[3, 4]`에서 3을 풀면 1이 풀려서 `[4, 1]` → 4가 먼저 나와 `3 4 1 2` (틀림). 힙은 늦게 들어온 1을 맨 앞으로 올려준다.
"순서 조건만 지키면 아무 순서나 OK"(백준 2252 줄 세우기)라면 일반 큐로 충분하다.

**C++** (vector + priority_queue)
```cpp
vector<int> adj[32005];
int indeg[32005];
// 입력: adj[a].push_back(b); indeg[b]++;

priority_queue<int, vector<int>, greater<int>> pq;   // 최소 힙
for (int i = 1; i <= N; i++) if (indeg[i] == 0) pq.push(i);
while (!pq.empty()) {
    int x = pq.top(); pq.pop();
    printf("%d ", x);
    for (int y : adj[x]) if (--indeg[y] == 0) pq.push(y);
}
```

**C** (연결 목록 + 직접 만든 힙)
```c
int head[32005], to[100005], nxt[100005], ecnt = 0;   // head[i] = -1로 초기화
void add_edge(int a, int b) { to[ecnt] = b; nxt[ecnt] = head[a]; head[a] = ecnt; ecnt++; }

// push/pop은 최소 힙 템플릿 그대로
for (int i = 1; i <= N; i++) if (indeg[i] == 0) push(i);
while (hsize > 0) {
    int x = pop();
    printf("%d ", x);
    for (int e = head[x]; e != -1; e = nxt[e])
        if (--indeg[to[e]] == 0) push(to[e]);
}
```

**C++ priority_queue 사용법**
- `priority_queue<int>`는 **최대 힙**(큰 값부터). 작은 값부터는 `priority_queue<int, vector<int>, greater<int>>`
- `push(x)` 넣기, `top()` 맨 위 보기, `pop()` 맨 위 지우기(값을 돌려주지 않음), `empty()`, `size()`
