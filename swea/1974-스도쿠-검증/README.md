# [D2] 스도쿠 검증

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV5Psz16AYEDFAUq
- 사이트 / 난이도: SWEA / D2
- 유형: 2차원 배열, 구현, 체크 배열
- 푼 날짜: 2026-11-13

## 문제
스도쿠는 숫자퍼즐로, 가로 9칸 세로 9칸으로 이루어져 있는 표에 1 부터 9 까지의 숫자를 채워넣는 퍼즐이다. *(원문 그림 생략)*

같은 줄에 1 에서 9 까지의 숫자를 한번씩만 넣고, 3 x 3 크기의 작은 격자 또한, 1 에서 9 까지의 숫자가 겹치지 않아야 한다. *(원문 그림 생략)*

입력으로 9 X 9 크기의 스도쿠 퍼즐의 숫자들이 주어졌을 때, 위와 같이 겹치는 숫자가 없을 경우, 1을 정답으로 출력하고 그렇지 않을 경우 0 을 출력한다.

### 제약 사항
1. 퍼즐은 모두 숫자로 채워진 상태로 주어진다.
2. 입력으로 주어지는 퍼즐의 모든 숫자는 1 이상 9 이하의 정수이다.

### 입력
입력은 첫 줄에 총 테스트 케이스의 개수 T가 온다.

다음 줄부터 각 테스트 케이스가 주어진다.

테스트 케이스는 9 x 9 크기의 퍼즐의 데이터이다.

### 출력
테스트 케이스 t에 대한 결과는 “#t”을 찍고, 한 칸 띄고, 정답을 출력한다.

(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

## 풀이 아이디어 (solution.cpp)
가로 9줄, 세로 9줄, 3×3 칸 9개를 각각 검사한다. 하나라도 같은 숫자가 두 번 나오면 0, 모두 통과하면 1.
- 검사할 묶음마다 `chk[10] = {0}`을 새로 만들고
- 숫자 `v`를 볼 때 `chk[v]`가 이미 1이면 **중복** → 바로 `return 0`
- 아니면 `chk[v] = 1`로 표시
- 3×3 칸은 왼쪽 위 좌표를 `(0,0), (0,3), (0,6), (3,0) ... (6,6)`으로 3씩 건너뛰며 돈다.

## 시간 / 공간 복잡도
- 81칸 × 3번 검사 → 상수 시간, 공간 O(1)

## 헷갈렸던 점, 배운 점
- 처음 코드의 실수 3가지 (정답 스도쿠도 0이 나왔음)
  1. 가로 검사에서 `chk[i] = 1` → 숫자가 아니라 **위치**를 표시했다. `chk[map[j][i]] = 1`이 맞다.
  2. 숫자가 1~9인데 `chk[9]`로 선언 → `chk[9]`는 배열 밖. **값의 최댓값 + 1** 크기로 선언(`chk[10]`).
  3. 정답일 때 `printf("%d", 1)`에 `\n`이 없어서 다음 `#2`가 같은 줄에 붙었다.
- 세 함수가 거의 같은 코드라 복사하다 한 곳만 틀리기 쉽다. 복사한 뒤 바뀌어야 할 부분을 한 번 더 확인하자.
- 체크 배열(방문 배열)로 중복을 찾는 패턴은 자주 나온다.
