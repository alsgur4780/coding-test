# [D2] 파리 퇴치

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV5PzOCKAigDFAUq
- 사이트 / 난이도: SWEA / D2
- 유형: 2차원 배열, 완전탐색
- 푼 날짜: 2026-11-13

## 문제
> 문제 지문은 추가 예정

## 풀이 아이디어 (solution.cpp)
N×N 격자에서 M×M 파리채를 놓을 수 있는 **모든 위치**를 다 해본다.
1. 파리채 왼쪽 위 칸 `(j, i)`를 `0 ~ N-M`까지 옮겨 가며
2. `chk(j, i, M)`으로 M×M 칸의 합을 구하고
3. 그중 최댓값을 출력한다.

예) N=5, M=2 → 왼쪽 위 칸은 0~3 (4×4 = 16곳)

## 시간 / 공간 복잡도
- O((N-M+1)² × M²) → N ≤ 15라 충분, 공간 O(N²)

## 헷갈렸던 점, 배운 점
- 처음엔 시작 위치를 `j < N`, `i < N`까지 돌려서 파리채가 **격자 밖**으로 나갔다.
  - 밖의 칸은 0이 아니라 **이전 테스트케이스 값**이 남아 있을 수 있고, 인덱스가 20을 넘으면 다음 행을 읽어 버린다.
  - 예) 1번 케이스가 4×4 전부 9, 2번 케이스가 2×2 전부 1, M=2 → 정답 4인데 28이 나옴
  - 고침: `j <= N - M`, `i <= N - M`
- SWEA는 `T` 입력 → 케이스마다 `#번호 답` 출력. 전역 배열은 케이스 사이에 초기화되지 않는다.
